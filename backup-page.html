Резервная копия «Мой онлайн»

Файл содержит историю и предпочтения. Пароль Rezka, код доступа и видеоссылки в него не включаются.

Введите тот же код, что настроен на телевизоре. Он передаётся только вашему серверу для доступа и в файл не сохраняется.

Сохранить копию с телевизора

На телевизоре: Мой онлайн → Настройки → Резервная копия → Подготовить для браузера. Затем нажмите кнопку ниже в течение пяти минут.

Передать файл на телевизор

Выберите ранее сохранённый файл. После передачи на телевизоре выберите «Получить из браузера» и подтвердите восстановление.

На сервере хранится только одна копия в памяти, доступная по коду. Она исчезнет через пять минут либо при перезапуске сервиса. Это временный перенос, не постоянное хранение.
