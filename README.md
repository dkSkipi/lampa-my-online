# Мой онлайн v0.6.0

Исправления по фото телевизора: для видео Rezka явно задаётся `launch_player: inner`, чтобы Lampa запускала встроенный веб-плеер, а не системный выбор внешнего Android-приложения. Предварительное меню качества убрано. Все доступные качества передаются плееру, озвучки — в его меню аудиодорожек.

Добавлен выбор проверочного фильма/сериала через REZKA_FILM_URL и поддержка получения сезонов и серий. Новый пример пользователя — «Во все тяжкие». Совместимость с реальным ответом serial-плеера rezka.si и конкретной сборкой Lampa на TCL ещё предстоит проверить: автотесты используют имитации ответов. Общий поиск каталога пока отсутствует.

## Обновление через GitHub / Render

1. Загрузите все файлы из архива в корень существующего GitHub-репозитория с заменой. Не загружайте сам ZIP вместо исходных файлов. Новые тестовые файлы тоже можно загрузить.
2. В Render → Environment оставьте существующие REZKA_LOGIN, REZKA_PASSWORD, MY_ONLINE_TOKEN, PUBLIC_BASE_URL. Их менять не нужно.
3. Добавьте **REZKA_FILM_URL** со значением:

```
https://rezka.si/series/thriller/646-vo-vse-tyazhkie-2008-latest.html
```

Разрешены только карточки фильмов/сериалов на https://rezka.si. Без этой переменной сохранится старый «Гладиатор» (1986). Адрес влияет только на проверочное видео, а не на автоматический поиск по текущей карточке Lampa.

4. Сохраните и разверните последний commit. Build Command `npm install`, Start Command `npm start`, Node.js 22+, Health Check Path `/health`, Root Directory пустой, если файлы в корне. `render.yaml` сам не меняет настройки существующего сервиса.
5. Дождитесь Live. `/health` должен показывать 0.6.0. `/api/rezka/status` после проверки — PAGE_AVAILABLE; `playerRecognized: true` означает, что поддержанный блок плеера найден. Для неправильного формата REZKA_FILM_URL сервер завершится с пояснением в логах; секреты в сообщение не включаются.
6. В Lampa замените старый адрес плагина на `https://lampa-my-online.onrender.com/plugin.js?v=0.6.0`. Полностью закройте приложение и откройте снова. Удалите старые дублирующие записи плагина.
7. Сохранённый код доступа должен остаться. Если нет — Мой онлайн → Ввести код доступа к серверу, введите прежний MY_ONLINE_TOKEN. Это не пароль Rezka.

## Проверка «Во все тяжкие»

Мой онлайн → **Rezka: запустить проверочный фильм** → озвучка → сезон → серия. После выбора серии видео запускается во встроенном плеере. Отдельного предварительного выбора качества нет. Для фильма без серий после озвучки сразу запускается видео.

Во время просмотра вызовите панель плеера: OK / стрелка вверх или вниз в зависимости от управления Lampa. Качество — кнопка качества, озвучка — меню аудиодорожек. При единственном качестве Lampa может скрыть кнопку качества.

Смена озвучки запрашивает поток **той же серии**, проверяя её наличие у новой озвучки. Если серия отсутствует или запрос завершился ошибкой, прежнее видео не останавливается и выбранная озвучка восстанавливается. При смене формата/качества используется штатное событие Lampa для сохранения позиции. Фактическое сохранение места зависит от проигрывателя и CDN и требует проверки на TCL. Внешние приложения VLC/медиаплеер TCL этот JavaScript-интерфейс не получают.

Если Android снова предложит список внешних приложений, не сохраняйте выбор наугад. Сообщите версию Lampa и результат после полного перезапуска; возможен перехват запуска другим расширением или отличие сборки. Выбор внешнего проигрывателя в общих настройках Lampa плагин не меняет: inner задаётся только для запуска Rezka из этого плагина.

Сейчас серия выбирается до запуска; для другой серии вернитесь к меню. Автопереход на следующую серию и общий поиск каталога ещё не реализованы. Любая карточка Lampa запускает один проверочный адрес, заданный на Render.

## Ошибки

| Код | Что означает |
|---|---|
| ACCESS_DENIED | Код в Lampa отличается от MY_ONLINE_TOKEN |
| ACCESS_CODE_NOT_CONFIGURED | Нет корректного MY_ONLINE_TOKEN (16–128 латинских букв/цифр/дефисов/подчёркиваний) |
| CHECKING | Стартовая проверка ещё идёт |
| AUTH_REQUIRED / LOGIN_REJECTED | Сайт требует входа / не подтвердил вход |
| PLAYER_NOT_RECOGNIZED | Карточка доступна, формат её плеера не поддержан |
| EPISODES_NOT_RECOGNIZED | Не удалось разобрать список серий из ответа сайта |
| EPISODE_NOT_AVAILABLE | У этой озвучки нет выбранной серии по данным сайта |
| SESSION_EXPIRED | Сессия закончилась, нужна проверка после перезапуска сервиса |
| STREAM_REJECTED / STREAM_INVALID_JSON | Запрос потока отклонён либо формат ответа неожиданный |
| STREAM_FORMAT_UNKNOWN | Упаковка ссылки не поддержана, URL не угадывается |
| NO_PLAYABLE_STREAMS | Нет допустимой HTTPS MP4/HLS-ссылки |
| WAIT_AND_RETRY | Запрос выполняется или прошло меньше двух секунд с последнего запроса потока |
| BLOCKED / RATE_LIMITED | Сайт ограничил сервер (403 / 429) |

Пришлите название шага, точный код ошибки или фото интерфейса без секретов. Пароль, код доступа, cookie и видеоссылки не присылайте.

## Сервер и безопасность

Вход на https://rezka.si/ajax/login/ — один раз при запуске при необходимости, без автоматических повторов. Cookie сохраняются только в памяти для запросов плеера; не выводятся в API, файлы и логи. Пароли берутся из Environment Render, не вставляются в plugin.js. На сторонние домены cookie и учётные данные не отправляются, редиректы ограничены. При ошибке авторизации нет автоматического перебора.

Публичны только безопасный статус `/api/rezka/status`, health, плагин и демонстрационный ролик. Метаданные `/api/rezka/movie`, сезоны/серии `/api/rezka/episodes?translator=ID`, ссылки `/api/rezka/stream?translator=ID&season=N&episode=M` требуют `Authorization: Bearer MY_ONLINE_TOKEN`. В URL код не принимается. Перед запросом потока серия проверяется по реальному списку для выбранной озвучки. Произвольные URL и ID карточек от клиентов не принимаются.

Кеш ссылок 60 секунд, списка серий 5 минут в памяти. Запросы сериализованы, повторный поток ограничен интервалом 2 секунды. Видео идёт напрямую CDN→телевизор, не через Render. Работа CDN может зависеть от IP, заголовков, срока ссылки и кодеков. streamReady=true означает получение допустимых ссылок, а не подтверждение просмотра на TV.

Разбор HTML не исполняет JavaScript страницы. Для кино используется get_movie, для сериала get_episodes/get_stream на `/ajax/get_cdn_series/`. Формат сверён с открытым клиентом https://github.com/n0madic/go-hdrezka (video.go, episodes.go, stream.go). Это собственный экспериментальный адаптер, не официальный API Rezka; авторизованный ответ сериала в среде разработчика не получен. Неизвестный формат даёт ошибку без подмены источника демонстрационным роликом. Премиум-метки не выдаются за доступные качества.

Интерфейс встроенного плеера сверён с https://github.com/yumata/lampa/blob/main/app.min.js : launch_player=inner, quality, voiceovers, PlayerPanel.quality/setTracks и событие quality. Сборки Lampa могут различаться. Если нет API переключения озвучки, начальное меню остаётся запасным способом выбора.

## Локальные проверки

Node.js 22+: `npm test` (или `node --test`), `npm start`. Внешних npm-зависимостей нет. Автотесты проверяют вход и cookie без настоящих аккаунтов, защиту API, разбор сезонов/серий, выбор серии в меню, передачу той же серии при смене озвучки, принудительный inner, отсутствие предварительного меню качества, качество/озвучки в плеере, обработку сетевых ошибок и поздних ответов. Это не тест настоящего телевизора и не проверка живого видеопотока.
