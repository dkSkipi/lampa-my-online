# Мой онлайн v0.7.0 — поиск фильма/сериала из карточки Lampa

Добавлен поиск на Rezka по названию открытой карточки Lampa. Результаты показывают название, год, тип и краткую информацию. Совпадения по году и типу поднимаются выше, но видео всегда выбирает пользователь: первый результат не запускается автоматически.

Выбор найденного фильма открывает его озвучки; для сериала дополнительно выбираются сезон и серия. Видео запускается во встроенном плеере Lampa без предварительного меню качества. Качество и озвучка переключаются в панели плеера, как в проверенной пользователем v0.6.

## Обновление существующего сервиса

1. Распакуйте ZIP и загрузите все файлы в корень существующего GitHub-репозитория с заменой. Добавьте новый `search-data.js` и новые тесты. Загружайте файлы, а не сам ZIP.
2. В Render сохраните работающие настройки REZKA_LOGIN, REZKA_PASSWORD, MY_ONLINE_TOKEN, PUBLIC_BASE_URL и REZKA_FILM_URL. **Новых переменных не требуется.** REZKA_FILM_URL теперь нужен только для стартовой диагностики/запасного пункта; для каждого найденного фильма менять его не надо.
3. Deploy latest commit. Команды прежние: Build `npm install`, Start `npm start`, Health Check `/health`, Node.js 22+. Файлы должны быть в корне или выбранном Root Directory.
4. Дождитесь Live; `/health` должен показать 0.7.0. Вход выполняется один раз при запуске, как прежде. Если сервер ещё проверяет Rezka, подождите завершения CHECKING в `/api/rezka/status`.
5. В Lampa замените старый адрес на `https://lampa-my-online.onrender.com/plugin.js?v=0.7.0`, полностью закройте Lampa и запустите заново. Уберите дубли старых записей.
6. Сохранённый код доступа остаётся тем же. Если Lampa его забыла, Мой онлайн → Ввести код доступа к серверу → прежний MY_ONLINE_TOKEN. Пароль Rezka вводится только в настройках Render, не в Lampa и не в чат.

## Проверка поиска

1. Откройте карточку нужного фильма/сериала в Lampa.
2. Мой онлайн → **Найти на Rezka: название**.
3. Выберите совпадение по названию, году и типу. Автоматического сопоставления по TMDB/Kinopoisk ID нет.
4. Выберите озвучку. У сериала — сезон и серию. Качество выбирается уже в плеере, из его панели.
5. Проверьте смену озвучки в меню аудиодорожек. Запрашивается та же серия того же сериала; при ошибке продолжает играть прежний поток.

Если ничего не найдено или совпадение другое, выберите **Ввести другое название** либо поиск по оригинальному названию, если оно есть в карточке. Отдельный пункт **Поиск по другому названию** доступен и в главном меню.

Первой проверкой удобно повторить «Во все тяжкие» через обычный поиск, затем открыть другой фильм. Пункт «Rezka: запустить проверочный фильм» сохранён для сравнения с рабочей v0.6, но не используется при обычном поиске.

Поиск пока обрабатывает первую страницу выдачи (максимум 40 результатов). Пагинация, поиск по внешним ID, автоматический переход между сериями, история выбранных серий и объединение одинаковых карточек не добавлены. Пустой результат не означает, что фильма наверняка нет на сайте: попробуйте другое название.

## Что проверено, а что ещё проверить

Пользователь подтвердил работу входа, сериалов и встроенного плеера на TCL в v0.6. В v0.7 проведены 20 автотестов, включая новый поиск, его защиту, разбор вложенной HTML-разметки, название/год, выбор результата в интерфейсе, запуск сериала, привязку video ID к потоку и смене озвучки, разделение кешей разных видео, неизвестные ID, прежние функции и ошибки.

Ответы поиска и авторизованных страниц в новых автотестах имитированы. Реальная авторизованная выдача поиска rezka.si в среде разработчика не получена; структуру и контракт сверяли по открытому клиенту go-hdrezka. Поэтому после обновления нужен один тест на настоящем сервере пользователя. Секреты не нужны для сообщения результата — достаточно названия шага или кода ошибки.

Протокол поиска: GET `/search/?do=search&subaction=search&q=...`, карточки `.b-content__inline_item` / `.b-content__inline_item-link`. Сверка: https://github.com/n0madic/go-hdrezka/blob/master/search.go и utils.go в том же репозитории. Это экспериментальный адаптер сайта, не заявленный официальный API Rezka.

## Данные выбранного видео

В отличие от одного глобального «текущего фильма», для каждой найденной карточки хранятся отдельные ID, путь, озвучки и метаданные. Запросы серий и потоков явно несут video ID. Ключи кешей включают video ID, перевод, сезон и серию, поэтому одинаковые ID переводов у разных фильмов не смешивают потоки. Поиск другого названия не меняет контекст уже открытого плеера.

Разрешённые карточки регистрируются по реальным результатам сайта. Клиент не передаёт произвольный URL; неизвестный video ID отклоняется до обращения к сайту. Разрешены только HTTPS-карточки rezka.si в категориях films/series/cartoons/animation. Фактический тип плеера определяется из карточки; неизвестный формат не угадывается. Ссылки с других хостов, учётными данными, query/hash игнорируются.

В памяти ограничены списки: до 200 карточек, до 50 поисковых запросов, до 200 записей серий и потоков. Кеш поиска 60 секунд, метаданных 10 минут, списка серий 5 минут, потоков 60 секунд. Если сервер перезапустился или старый результат вытеснен, повторите поиск. Объект, с которым играет текущий плеер, не заменяется другим фильмом.

## Защита и API

Публичны `/health`, `/plugin.js`, `/api/demo`, `/api/rezka/status`. Они не возвращают логин, пароль, код, сессионные cookie или видеоссылки.

Все операции Rezka требуют `Authorization: Bearer MY_ONLINE_TOKEN`:

| Запрос | Назначение |
|---|---|
| GET /api/rezka/search?q=Название | Поиск названия от 1 до 200 символов |
| GET /api/rezka/movie?video=ID | Озвучки выбранного результата |
| GET /api/rezka/episodes?video=ID&translator=ID | Список сезонов/серий этой озвучки |
| GET /api/rezka/stream?video=ID&translator=ID&season=N&episode=M | Ссылки серии; для фильма season/episode не нужны |

Без video используется только старая диагностическая карточка для совместимости запасного пункта. Старый публичный `/api/search` больше не отдаёт тестовую пустую выдачу: отвечает 410 API_MOVED. Настоящий поиск всегда защищён.

Cookie и пароль остаются на сервере, в памяти и Environment соответственно. Вход не повторяется автоматически при ошибках. Сторонним хостам данные входа не отправляются; редиректы ограничены. Текст ответа сайта не публикуется при ошибках. HTML не выполняется через eval, в меню поиска передаются экранированные подписи. Код доступа не передаётся в URL и не встраивается в plugin.js.

Видео идёт напрямую CDN→телевизор. Ссылка может иметь срок действия, ограничения IP/заголовков/кодеков. Если меняете озвучку сразу после старта, может сработать пауза между запросами потоков (2 секунды); подождите и повторите. `streamReady: true` означает получение ссылки, а не автоматическое доказательство декодирования на TV.

## Ошибки

| Код | Действие |
|---|---|
| ACCESS_DENIED | Введите прежний MY_ONLINE_TOKEN в Lampa |
| ACCESS_CODE_NOT_CONFIGURED | Проверьте наличие корректного MY_ONLINE_TOKEN на Render |
| API_MISMATCH | Обновите все файлы сервера и запись плагина до v0.7 |
| CHECKING | Дождитесь стартовой проверки |
| AUTH_REQUIRED / LOGIN_REJECTED | Проверьте прежние настройки входа в Render; не повторяйте вход многократно |
| SEARCH_FORMAT_UNKNOWN | Выдача сайта не совпала с поддержанным форматом; сообщите этот код |
| VIDEO_SELECTION_EXPIRED | Повторите поиск и снова выберите результат |
| PLAYER_NOT_RECOGNIZED | Неизвестный формат плеера конкретного результата |
| EPISODES_NOT_RECOGNIZED | Неизвестный формат списка серий |
| EPISODE_NOT_AVAILABLE | У выбранной озвучки нет этой серии |
| SESSION_EXPIRED | Нужен перезапуск сервиса для новой проверки входа |
| STREAM_REJECTED / STREAM_INVALID_JSON | Сайт отклонил запрос или изменил ответ |
| STREAM_FORMAT_UNKNOWN / NO_PLAYABLE_STREAMS | Неподдержанная упаковка или нет доступных MP4/HLS |
| WAIT_AND_RETRY | Подождите завершения другого запроса и повторите |
| BLOCKED / RATE_LIMITED | Сайт ограничил сервер (403 / 429) |

При проблеме сообщите название фильма/сериала и код. Пароль, токен, cookie, настройки Environment и видеоссылки не присылайте.

## Локальная проверка

Node.js 22+: `npm test` / `node --test`, `npm start`. Внешних npm-зависимостей нет. Проверяется локальный HTTP-сервер и имитация интерфейсов Lampa. Настоящий TCL и авторизованная выдача сайта не входят в автотесты.
