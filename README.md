# Мой онлайн — Lampa v0.1

Первый прототип кнопки «Мой онлайн» + Node.js API для Render + тест воспроизведения в Lampa.

**Важно:** это не готовый клиент Rezka. Авторизация, поиск Rezka, озвучки и сезоны пока не реализованы. Не передавайте пароли или cookie в Render. Сервер не проксирует видео.

## 1. GitHub

Создайте репозиторий `lampa-my-online` и загрузите в его корень все файлы из этого архива: `package.json`, `server.js`, `plugin.js`, `README.md`, `.gitignore`.

## 2. Render

Render → New → Web Service → подключить репозиторий GitHub:
- Runtime: Node
- Build Command: `npm install`
- Start Command: `npm start`
- Instance: Free (если доступен)

После Deploy получите адрес вида `https://MY-NAME.onrender.com`.
Откройте `https://MY-NAME.onrender.com/health` — ожидается `{ "ok": true, ... }`.

## 3. Lampa на TCL

Настройки → Расширения / Плагины → Добавить плагин → вставьте **адрес вашего Render**:

`https://MY-NAME.onrender.com/plugin.js`

Перезапустите Lampa и откройте карточку фильма — появится «Мой онлайн».

## 4. Проверка плеера

В Lampa найдите фильм **Big Buck Bunny** и откройте «Мой онлайн» — появится тестовая ссылка для воспроизведения. Используется общедоступный демонстрационный MP4 из каталога тестовых видео Google, а не Rezka. Это проверяет связку: Lampa → API → плеер.

Для других названий в прототипе будет сообщение «Пока нет источников». Это ожидаемое поведение.

## Дальнейшее развитие

Вместо массива `demo` в `server.js` можно подключить разрешённый API/каталог с результатами следующего формата:

```json
{"provider":"source-name","items":[{"id":"id","title":"Название","versions":[{"name":"Оригинал","quality":"1080p","url":"https://example.org/authorized-video.mp4"}]}]}
```

Текущий плагин уже умеет показать варианты и передать прямой HTTPS MP4/HLS поток в `Lampa.Player`. DRM, cookies в HTTP-заголовках, защищённые сайты и обход авторизации не поддерживаются.

## Ограничения

- Кнопка проверена по паттерну существующих плагинов, но **не проверена на вашем TCL**.
- Некоторые сборки Lampa отличаются API и могут потребовать правок.
- Free Web Service на Render может засыпать после периода бездействия и долго отвечать на первый запрос.
- Демо-видео может быть недоступно в конкретной сети или сборке плеера.
- CORS открыт только для общедоступного API без учётных данных; добавлять токены, cookie или секреты в ответы API нельзя.
