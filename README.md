## Однократное обновление до постоянного адреса

1. Распакуйте ZIP. Загрузите все файлы в корень своего существующего GitHub-репозитория с заменой. Архив вместо исходников загружать не надо.
2. Настройки Render не меняются: REZKA_LOGIN, REZKA_PASSWORD, MY_ONLINE_TOKEN, PUBLIC_BASE_URL и REZKA_FILM_URL оставьте прежними. Новых переменных нет.
3. Разверните последний commit. Build `npm install`, Start `npm start`, Node.js 22+, Health Check `/health`; Root Directory соответствует расположению файлов.
4. Дождитесь Live. https://lampa-my-online.onrender.com/health должен вернуть version=0.10.1 и apiVersion=1.
5. **В последний раз замените адрес записи плагина в Lampa на постоянный:**

```
https://lampa-my-online.onrender.com/plugin.js
```

Без `?v=...`. Удалите старые дублирующие записи и полностью закройте/откройте Lampa.

Дальше при совместимых обновлениях достаточно обновить файлы GitHub, дождаться развёртывания Render и перезапустить Lampa. Сервер отдаёт JS с Cache-Control: no-store, а ответы API содержат отдельную версию протокола apiVersion=1. Версия выпуска больше не требует изменения URL. При несовместимом изменении протокола всё равно может понадобиться обновление клиента. Это не фоновая установка кода в уже открытом плеере.

Если Render Auto-Deploy отключён, запускайте Deploy latest commit вручную. Если сервер временно недоступен, Lampa может использовать собственную сохранённую копию расширения: после восстановления связи перезапустите приложение. Постоянный URL при этом остаётся тем же.

## Позиция и просмотренные серии

Сохраняются последняя запущенная серия/сезон/озвучка и позиции отдельных серий. Во время просмотра позиция пишется примерно раз в 5 секунд; при штатном закрытии её дополнительно сохраняет стандартный механизм Timeline Lampa. При аварийном выключении последние несколько секунд могут потеряться.

Позиция передаётся штатному Timeline встроенного плеера. Восстановление учитывает настройку Lampa «Продолжать просмотр» / player_timecode: если включён вопрос, Lampa спросит; если выбрано всегда начинать заново, это поведение сохраняется. Фактическая перемотка зависит от сборки Lampa и поддержки CDN. Сохранение секунд проверено в логике; работу перемотки на TCL необходимо подтвердить.

В списке серий:

- **✓** — просмотрено не менее 95% либо получено событие окончания;
- **▶** и процент — серия начата;
- без отметки — сохранённого просмотра нет.

«Продолжить» открывает сохранённую серию с её позицией. Если она уже просмотрена, выбирается следующая доступная серия. Если следующей нет или сохранённый эпизод исчез, остаётся обычный выбор — случайная серия автоматически не запускается. Ручной выбор просмотренной серии начинает её заново.

Смена озвучки текущей серии не сбрасывает её Timeline. Разные монтажи могут иметь разную продолжительность, поэтому одинаковая секунда не всегда соответствует одинаковой сцене.

## Кнопка в карточке

После первого выбора результата поиска и запуска видео при следующем открытии карточки Lampa появляется **Продолжить онлайн** рядом с «Мой онлайн». Она использует сохранённое сопоставление карточки Lampa и выбранного ID Rezka.

Для получения свежих данных кнопка повторяет исходный поиск и проверяет наличие того же ID; затем открывает сохранённую озвучку и серию. Повторно выбирать поисковое совпадение не требуется. Если результат больше не найден, предлагается поиск заново, а не другое одноимённое видео. Временные видеоссылки не хранятся в сопоставлении.

Кнопка появляется после нового открытия карточки; если первый просмотр был запущен из уже открытой карточки, выйдите из неё и откройте снова. У очищенной истории или другого устройства собственного сохранённого соответствия не будет.

## Предпочитаемые озвучка и качество

В настройках укажите название студии или его часть, например LostFilm. Для нового видео без личной истории совпавшая озвучка выбирается автоматически. Если совпадения нет, остаётся обычный список. Для уже просмотренного видео приоритет имеет сохранённая личная озвучка.

Качество: авто, 360p, 480p, 720p, 1080p, 2160p. При отсутствии желаемого разрешения выбирается доступное не выше него, а если такого нет — минимальное доступное. Это предпочтение, а не обещание наличия 4K у источника. «Авто» сохраняет стандартный выбор Lampa. Качество по-прежнему можно переключить вручную в панели плеера.

Код доступа находится в тех же настройках. Используйте прежний MY_ONLINE_TOKEN; это не пароль Rezka. Изменения предпочтений применяются при следующем запуске видео. Выбор другой озвучки во время просмотра сохраняется для этого видео, не заменяя глобальное название студии для всех фильмов.

## Ошибки и обновление ссылки

При временной потере сети, таймауте или WAIT_AND_RETRY плагин один раз повторяет запрос примерно через 2,5 секунды. Ошибки авторизации, кода доступа, подписки, неизвестного формата и отсутствующей серии автоматически не повторяются. Бесконечных попыток и повторных входов нет.

Если сам встроенный плеер сообщает ошибку, появляется выбор **Обновить ссылку и повторить** / **Закрыть плеер**. Обновление запрашивает поток без использования минутного кеша, сохраняет Timeline и прежнее доступное качество. Это не исправляет неподдерживаемый кодек, блокировку CDN или отсутствие доступа у аккаунта.

Если не загрузилась следующая серия, плеер закрывается для сброса внутреннего состояния ожидания Lampa, затем предлагает **Повторить** или **Вернуться к карточке**. Неудачная серия не отмечается начатой, прежний прогресс сохраняется. Повтор использует свежую ссылку. Ответ, пришедший после закрытия плеера, не запускает видео заново.

Восстановление сессии аккаунта по-прежнему требует перезапуска сервиса. Пароль автоматически не отправляется заново при каждом сбое видео. Если интерфейс плеера в вашей сборке не отдаёт событие error, его собственное сообщение останется основным; новая кнопка восстановления может не появиться.

## Серии и автопереход

Плейлист включает доступные серии выбранной озвучки, переходы между сезонами, предыдущую/следующую серию и список. Ссылки получаются в момент выбора; старый URL при возврате к эпизоду не переиспользуется.

Автопереход после окончания зависит от существующего пункта **Настройки Lampa → Плеер → Следующая серия**. Плагин не меняет этот переключатель. После последней серии цикл на первую не запускается. Отсчёт/новые подсказки перед переходом не добавлены.

## Локальные данные и совместимость

Старый ключ `my_online_watch_v1` сохранён: выбор из v0.8 не теряется. К нему добавлена карта прогресса серий. Ключ `my_online_card_links_v1` хранит соответствия карточек, `my_online_preferences_v1` — предпочтения. Код доступа остаётся по прежнему ключу.

В истории до 100 видео и до 100 последних записей эпизодов на видео; для очень длинного сериала старые отметки могут вытесняться. История локальная, не синхронизируется через Render и не является облачной историей CUB. Очистка данных Lampa удалит её.

Пароли, cookie и временные видеоссылки в историю не записываются. Они не нужны для сообщения об ошибке. Не присылайте пароль, MY_ONLINE_TOKEN, cookie, страницу Environment или адрес потока. Достаточно названия видео, действия и кода ошибки.

## Сервер

Защита API и ограничение домена сохраняются. Поиск/метаданные/серии/потоки требуют заголовок Authorization с кодом; неизвестные video ID и произвольные URL отклоняются. Вход — один раз при запуске; cookie только в памяти. Публичные health/status не раскрывают аккаунт и ссылки.

Добавлен параметр refresh=1 к защищённому запросу потока: он обходит кеш, но сохраняет ограничение частоты. Сетевые ошибки от провайдера получают безопасный код NETWORK. Сервис не проксирует видео: CDN связывается с телевизором напрямую.

Поиск пока использует первую страницу сайта, не имеет пагинации и автоматического сопоставления по внешним ID. Предыдущая настройка REZKA_FILM_URL сохраняется только для стартовой проверки входа; фиксированный просмотр пользователю не предлагается.

## Проверка на TCL после обновления

1. Запустите серию, посмотрите/перемотайте к середине, штатно закройте плеер. Откройте карточку заново и нажмите «Продолжить онлайн». Проверьте позицию.
2. Откройте список серий: должна появиться отметка начатой серии. Досмотрите/перемотайте к концу и проверьте отметку ✓ и следующую серию через «Продолжить».
3. Задайте предпочитаемую озвучку и качество; проверьте новое видео без истории. Затем проверьте ручное переключение в плеере.
4. Проверьте штатные следующий/предыдущий эпизоды и сохранение озвучки. Новый отсчёт не должен появляться.
5. При реальном сетевом сбое запишите, сработал ли повтор и/или выбор обновления ссылки. Не нужно многократно перезапускать сервис или менять пароль ради теста.
