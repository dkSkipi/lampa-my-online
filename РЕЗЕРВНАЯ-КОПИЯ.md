# Резервная копия — v0.10.1

В копию входят история, позиции и отметки серий, выбранные озвучки, предпочтения качества и соответствия карточек Lampa/Rezka. Пароль Rezka, MY_ONLINE_TOKEN, cookie и временные видеоссылки не включаются. Это ручное резервное копирование, не автоматическая синхронизация.

## Обновление

Загрузите все файлы ZIP в корень существующего GitHub-репозитория с заменой, дождитесь развёртывания Render и перезапустите Lampa. Особенно важны новые backup.js, backup-transfer.js, backup-page.html, backup-page.js и тесты: сервер теперь включает библиотеку копирования в ответ /plugin.js, поэтому менять только plugin.js нельзя.

Environment Render и постоянный адрес `https://lampa-my-online.onrender.com/plugin.js` не меняются. /health должен показать 0.10.1.

«Мой онлайн» теперь ставится первой кнопкой стандартной панели карточки фильма/сериала, «Продолжить онлайн» — сразу после неё. Действия других кнопок не изменяются.

## Сохранить копию с TCL

1. На телевизоре: **Мой онлайн → Настройки → Резервная копия → Подготовить для браузера (для ТВ)**.
2. Подтвердите временную передачу истории вашему Render-сервису на пять минут.
3. На компьютере или телефоне откройте **https://lampa-my-online.onrender.com/backup**.
4. Введите тот же код доступа MY_ONLINE_TOKEN, что используется в Lampa. Пароль Rezka здесь не нужен. Код передаётся серверу для доступа, но в файл не сохраняется.
5. Нажмите **Скачать подготовленную копию**. Проверьте, что JSON-файл появился в загрузках, и сохраните его у себя.

Именно скачанный файл является долговременной резервной копией. На сервере одна подготовленная копия хранится только в оперативной памяти пять минут и исчезает при перезапуске. Это перенос, не постоянное облачное хранение. Если время истекло, подготовьте копию на ТВ ещё раз. Для нескольких устройств выполняйте переносы по одному: временный слот общий для вашего сервиса.

## Восстановить копию на телевизоре

1. Установите плагин и настройте код доступа. Код намеренно не переносится из резервной копии. Закройте воспроизведение видео.
2. На компьютере/телефоне откройте `/backup`, введите код, выберите свой JSON-файл и нажмите **Передать копию на сервер для телевизора**. Подтвердите передачу.
3. В течение пяти минут на ТВ: **Мой онлайн → Настройки → Резервная копия → Получить из браузера**.
4. Проверьте показанное количество видео/записей. Выберите **Объединить с текущей историей** либо **Заменить историю и предпочтения**, затем отдельно подтвердите восстановление.
5. Откройте карточку заново и проверьте сохранённую серию/позицию и настройки.

При объединении у каждого эпизода сохраняется более новая позиция, а независимые записи объединяются. Последняя озвучка и серия берутся из более новой записи видео. Предпочтения, присутствующие в копии, заменяют текущие. При полной замене изменяются только три ключа этого плагина; другая история Lampa, код доступа, аккаунты и другие расширения не затрагиваются.

При воспроизведении импорт запрещён, чтобы плеер не перезаписал восстановленный прогресс. При ошибке записи выполняется откат прежних данных. Если и откат не удался из-за памяти устройства, об этом выводится отдельное сообщение. Сам файл копии не удаляется.

## Сохранение/открытие файла на самом устройстве

В меню есть также **Сохранить файл на этом устройстве** и **Восстановить из файла на этом устройстве**. Они используют стандартные браузерные загрузку файла и выбор JSON-файла. Поддержка зависит от браузера/Android TV WebView; отдельные сборки не показывают диалог или не сохраняют Blob-файлы. Для TCL рекомендуем перенос через браузер компьютера/телефона, описанный выше.

Сообщение «Запрошено сохранение файла» не доказывает, что загрузка действительно завершилась: проверьте загрузки. Стандартные механизмы описаны в MDN: https://developer.mozilla.org/en-US/docs/Web/API/HTMLAnchorElement/download и https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/input/file .

## Формат и ограничения

JSON, format=`lampa-my-online-backup`, schemaVersion=1, максимум 2 МБ. Читаются только разрешённые поля my_online_watch_v1, my_online_card_links_v1, my_online_preferences_v1. Неизвестный формат/версия отклоняются. Неизвестные поля, секреты в посторонних ключах, опасные ключи и записи с URL не применяются. Старые записи без прогресса эпизодов поддерживаются.

История и предпочтения внутри файла читаемы, файл не зашифрован. Храните его у себя, присылать в чат не нужно. Ограничения истории прежние: до 100 видео и до 100 записей эпизодов на видео; при превышении остаются более новые.

Передача идёт только через ваш Render-сервис. Новый `/api/backup` требует прежний Authorization Bearer-код для чтения и записи. Результаты не кешируются; копия не пишется на диск. Страница `/backup` не подключает сторонние ресурсы, не сохраняет код в браузерное хранилище и не вставляет данные копии как HTML. Посторонний сайт не получит доступ без кода.

## Проверки

45 автотестов прошли: прежние функции и новые проверки копирования/восстановления, исключения секретов, слияния более новых позиций, некорректных файлов/размера, отката, пятиминутного срока, защиты API и CORS, подтверждения переноса/импорта, запрета импорта при открытом видео и порядка кнопок без дублей.

Тесты используют локальный сервер и имитацию интерфейсов Lampa. Реальные файловые диалоги и перенос на TCL ещё нужно проверить. Секреты пользователя для проверки не использовались.
